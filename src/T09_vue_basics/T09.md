# Vue Basics

---

# Why Vue?

- Easy to start: write mostly HTML, CSS, and JavaScript.
- Clear syntax for beginners.
- Great for building interactive web pages.

---

# Vue App Structure

`main.js`

```js
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
```

- `createApp(...)` creates your app.
- `.mount("#app")` tells Vue where to render on the page.

---

# Template Syntax

`App.vue`

```js
<script setup>
const msg = "This is from a variable.";
const num = 1;

function sum(a, b) {
  return a + b;
}
</script>

<template>
  <div>This is just like HTML.</div>
  <div>{{ msg }}</div>
  <div>Calculation: {{ num + 1 }}</div>
  <div>Call function: {{ sum(1, 2) }}</div>
</template>
```

---

# Template Syntax

- `{{ ... }}` is called interpolation.
- You can use it to display variables, calculations, and function calls.
- You can also use it to display the result of expressions.

# Style

`App.vue`

```vue
<template>
  <div class="wrapper">
    <h2 class="header">Test CSS</h2>
  </div>
</template>

<style scoped>
.wrapper {
  margin: 0.5em auto;
  width: 95vh;
}

.header {
  color: teal;
}
</style>
```

- In Vue templates, use `class` (not `className`).

# Event Handling

`App.vue`

```vue
<script setup>
function handleClick() {
  alert("Hello!");
}
</script>

<template>
  <button @click="handleClick">Click</button>
</template>
```

- `@click` listens for click events.

---

# Component

- Components are reusable UI blocks.
- Each component has its own template, script, and style.

---

`components/NavBar.vue`

```vue
<template>
  <div class="nav">
    <span>Home</span>
    <span>About Me</span>
  </div>
</template>

<style scoped>
.nav {
  display: flex;
  gap: 0.5em;
  color: teal;
  background-color: rgb(243, 243, 243);
  padding: 0.2em 0.5em;
}
</style>
```

---

`App.vue`

```vue
<script setup>
import NavBar from "./components/NavBar.vue";
</script>

<template>
  <NavBar />
  <div class="wrapper">...</div>
</template>
```

# Counter App

```vue
<script setup>
import { ref } from "vue";

const counter = ref(0);

function handleClick() {
  counter.value += 1;
}
</script>

<template>
  <div>{{ counter }}</div>
  <button @click="handleClick">Add</button>
</template>
```

- `ref(...)` creates reactive state.

---

# Common Mistake

- In JavaScript, use `counter.value`.
- In template, use `{{ counter }}`.

---

# Form App (`v-model`)

```vue
<script setup>
import { ref } from "vue";

const name = ref("");
</script>

<template>
  <input v-model="name" placeholder="Type your name" />
  <p>Hello, {{ name }}</p>
</template>
```

- `v-model` keeps input and state in sync.

---

# Todo App Idea

- Create `todos` list using `ref([])`.
- Add new item from an input box.
- Show list with `v-for`.
- Prevent adding empty text.

```vue
<li v-for="(todo, index) in todos" :key="index">{{ todo }}</li>
```

---

# Summary

- Template syntax: `{{ ... }}`
- Events: `@click`
- Reactive state: `ref(...)`
- Two-way binding: `v-model`
- List rendering: `v-for`
