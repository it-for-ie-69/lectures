# Running PostgreSQL with Docker

```bash
DB_NAME='g99_db'
DB_VOLUME_NAME='g99_volume'
DB_PASSWORD='6&zi9!%BYCUZo6B'
DB_PORT='4099'
```

`docker run -d --name ${DB_NAME} -e POSTGRES_PASSWORD=${DB_PASSWORD} -v ${DB_VOLUME_NAME}:/var/lib/postgresql -p ${DB_PORT}:5432 postgres:latest`

> For windows user please use Git Bash.

---

# Delete Database

- Run `docker rm -f ${DB_NAME}`
- Run `docker volume rm ${DB_VOLUME_NAME}`

---

# Prepare Database

- `docker exec -it ${DB_NAME} bash`
- `psql -U postgres`
- `CREATE DATABASE app_db;`
- `\c app_db`

---

- Create table

```sql
CREATE TABLE IF NOT EXISTS
  todos (
    id serial PRIMARY KEY,
    title VARCHAR(50) NOT NULL,
    completed BOOLEAN NOT NULL DEFAULT FALSE,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
  );
```

- Check the table with `\dt` and `SELECT * FROM todos;`
